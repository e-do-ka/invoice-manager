実行はコンテナ経由: `docker compose exec web bin/rails test`

## 実行方法

```bash
docker compose exec web bin/rails db:test:prepare
docker compose exec web bin/rails test
```

CI: `.github/workflows/ci.yml` の test ジョブ（PostgreSQL 16 サービス付き）が push / PR ごとに自動実行する。
